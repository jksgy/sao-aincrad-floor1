# 《刀剑神域：艾恩葛朗特第一层》同人像素 RPG 原型 — 说明

同人学习用途原型，非官方产品。角色与世界观版权归原作者所有。

## 一、如何启动（重要）

**请双击桌面上的「刀剑神域第一层原型」文件夹里的 `AincradProto.exe` 开始游玩。**

- 该文件夹是可直接游玩的分发版（单文件 exe，已内嵌全部资源）。
- 不要从 `D:\2DSAO`（开发工作区）里直接双击 exe：该目录具有沙箱/安全策略限制，exe 在其中启动会被系统拦截并崩溃（表现为“双击无反应”）。把 exe 复制到桌面或任意普通文件夹后即可正常运行。
- 无需安装 Godot、Python、Node.js 或任何其他运行环境；完全离线，不联网、无账号、无外部 API。
- 默认窗口 1280×720（内部逻辑分辨率 640×360，恰好 2 倍整数缩放；全屏 1920×1080 为 3 倍整数缩放）；文字在窗口分辨率下原生渲染，清晰锐利；像素图最近邻采样。
- 标题界面选择「新游戏」输入名字（留空为「旅人」）；开场约 30 秒，按 Esc 可跳过。
- 有存档时「继续游戏」可用。

## 二、操作按键

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动（八方向，对角自动归一化） |
| J | 普通攻击（三段连击，倍率 1.0/1.15/1.4，消耗体力 6） |
| K | 闪避（0.28 秒，中途约 0.16 秒无敌，消耗体力 20） |
| L | 剑技「突进斩」（2 级解锁，1.8 倍伤害，冷却 6 秒，消耗体力 30） |
| Q | 使用小型恢复药水（恢复 40，冷却 2 秒） |
| E | 交互 / 对话 / 开宝箱 / 激活机关 / 存档点 |
| I | 背包与装备 |
| M | 当前区域地图 |
| Esc | 暂停菜单 / 关闭当前菜单 |

输入优先级：暂停菜单 > 对话和商店 > 背包 > 场景交互 > 战斗操作。菜单打开时不会误触攻击或药水。

## 三、存档与读档

- 存档位置：`%APPDATA%\AincradProto\savegame.json`（同目录下有 `.bak` 备份与 `logs\` 运行日志）。
- 存档时机：城镇北侧教堂恢复点（手动，同时回满生命与体力）；Boss 门前自动存档；通关后自动保存。
- 读档：标题界面「继续游戏」；死亡后选择「读取最近存档」。
- 写入采用“临时文件 + 替换 + 备份”，写入成功才提示“保存成功”；主存档损坏时自动尝试备份。
- 恢复点/出生点均位于可行走位置；读档时校验坐标，非法则回退到该地图安全点。

## 四、已实现内容

- 完整流程：标题 → 开场（可跳过）→ 起始之镇 → 草原 → 迷宫 A/B/C → 守层 Boss 房 → 第一层通关结算 → 返回城镇。
- 城镇（80×60）：喷泉广场、铁匠铺、装备店、杂货店、教堂恢复点、公告牌、6+ 名居民（部分会走动）、训练木桩与桐人；安全区，无敌人、自动恢复。
- 草原（120×90）：野猪近郊、狼群树林、东侧遗迹、两条探索支路、隐藏宝箱（旧护符）、休息地、水面动画。
- 迷宫 A/B/C（56×40）：示范机关门、两处封印机关（独立 ID）、补给宝箱、铁制长剑支路奖励、Boss 门。
- Boss 房（40×28）：两阶段狗头人领主（横向重斩 110° 扇形、直线冲锋锁定、近身震击；40% 血量狂暴转阶段），入场关门、胜利开门、预警不扣血、死亡正确重置、通关状态持久化。
- 战斗：三段普攻（扇形 75°、输入缓冲、连击窗口）、闪避无敌帧、突进斩、受伤无敌闪烁与击退、体力/恢复规则、同一攻击对同一目标只结算一次。
- 敌人：野猪（低头冲撞）、草原狼（扑咬）、迷宫守卫（长前摇挥击）；视野 + 视线遮挡判定、追击/脱战返回恢复、掉落与经验只发一次、重进地图刷新。
- 成长：1–5 级（阈值 0/40/110/220/380，每级 +15 HP/+4 SP/+2 攻/+1 防）；装备（武器/护甲/饰品）实时影响数值并显示比较；背包 20 格、药水堆叠 20、背包满时掉落留在场景中。
- 任务：四条主线（教学→野猪委托→封印调查→第一层攻略），状态机（未接受/进行中/可交付/已完成/奖励已领取），乱序探索、重复对话、读档均不会卡死或重复发奖。
- 界面：HUD（血/体力/经验/任务目标/药水/剑技冷却）、对话（逐字显示、可跳句、选项）、背包、地图（探索迷雾、出口/恢复点/机关/Boss 门标记）、暂停、设置（音量、全屏、震屏开关）、Boss 血条、结算（时长/等级/击杀数）。
- 音乐 4 首循环（城镇/野外/迷宫/Boss）+ 全部战斗与界面音效，切换地图淡入淡出，音量分层可调。
- 失焦自动暂停；退出无残留进程。
- 全部素材（像素图、音频、中文字体 Noto Sans SC）内置于游戏，无外部依赖。
- 可调数值集中配置于 `project/data/*.json` 与 `data/maps/*.txt`（物品/敌人/技能/任务/对话/平衡参数）。

## 五、已知问题

- **运行位置限制**：受本机开发工作区的目录安全策略影响，exe 放在 `D:\2DSAO` 内直接双击会崩溃；请使用桌面上的分发文件夹（或复制到任意普通目录）。游戏本体在正常目录下运行稳定。
- 音效为程序生成的简易合成音，音乐为芯片音风格；无语音。
- 解析度不是整数倍的窗口尺寸下，像素图会按最近邻非整数缩放（轻微闪烁）；建议使用默认 1280×720 或全屏 1920×1080。

## 六、工程目录

- `project/`：完整 Godot 4.4.1 工程（project.godot、场景、脚本、资源、导出配置）。
- `build/`：Windows 导出成品（AincradProto.exe，内嵌 pck）——注意见第五节运行位置限制。
- `tools/`：资产生成脚本（像素美术/音频/地图）、下载与校验工具、测试日志。
- `project/tests/`：headless 自动化测试（193 项）与验证探针（不进入导出包）。
- `验证截图/`：实际运行画面截图 12 张（1280×720，来自导出包本身的自动巡游）。
- `验证记录.md`：完整验证情况与本次崩溃问题的根因记录。

## 七、重新导出（可选）

用 Godot 4.4.1-stable 打开 `project/`，在「项目 → 导出」选择 “Windows Desktop” 预设即可；导出模板目录为 `%APPDATA%\Godot\export_templates\4.4.1.stable\`。
