# 刀剑神域：艾恩葛朗特 第一层 —— 同人像素 RPG 原型

一个使用 **Godot 4.4.1 + GDScript** 制作的《Sword Art Online》艾恩葛朗特篇同人原型：俯视角像素探索 + 即时近战 + 任务链 + 三张迷宫 + 两阶段守层 Boss，可导出为 Windows 单文件 exe 离线运行。

> 同人学习用途，非官方产品；角色与世界观版权归原作者所有。全部美术、音频为程序生成，中文字体使用开源的 Noto Sans SC。

## 主要内容

| 系统 | 说明 |
|------|------|
| 地图 | 起始之镇（80×60）、草原（120×90）、迷宫 A/B/C（56×40）、守层 Boss 房（40×28） |
| 战斗 | 三段普攻（扇形 75°、输入缓冲、连击窗口）、闪避无敌帧、剑技「突进斩」、受击无敌与击退 |
| 敌人 | 野猪（冲撞）、草原狼（扑咬）、迷宫守卫（长前摇挥击）；视野/视线判定、脱战返回、掉落与经验只结算一次 |
| Boss | 狗头人领主：横向重斩（110° 扇形预警）、锁定冲锋、近身震击；40% 血量二阶段狂暴；入场关门、胜利开门 |
| 成长 | 1–5 级、经验阈值、装备（武器/护甲/饰品）实时影响数值、背包 20 格与药水堆叠 |
| 任务 | 四条主线：教学 → 野猪委托 → 封印调查 → 第一层攻略；状态机含「可交付/已领取」，防重复发奖、防卡死 |
| 界面 | HUD、逐字对话与选项、背包、探索地图、暂停/设置、Boss 血条、通关结算 |
| 存档 | `user://` 原子写入 + 备份回退；恢复点手动存档、Boss 门前自动存档、通关保存 |

## 操作

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动（八方向，对角归一化） |
| J | 普通攻击（三段连击） |
| K | 闪避（中途无敌，可穿过敌人但不会停在敌人体内） |
| L | 剑技「突进斩」（2 级解锁，冷却 6 秒） |
| Q | 使用小型恢复药水 |
| E | 交互 / 对话 / 宝箱 / 机关 / 存档点 |
| I | 背包与装备 |
| M | 地图 |
| Esc | 暂停 / 关闭菜单 |

## 如何运行

**方式一：直接玩已导出的版本**

`build/AincradProto.exe`（约 100 MB，单文件内嵌资源，双击即玩）。由于 GitHub 单文件限制 100 MB，exe 未纳入仓库，请放在 **Releases** 附件中下载。存档位置：`%APPDATA%\AincradProto\savegame.json`。

**方式二：从源码运行 / 重新导出**

1. 安装 **Godot 4.4.1-stable**（标准版，非 .NET）。
2. 用 Godot 打开 `project/`（首次会导入资源，约 1 分钟）。
3. 按 F5 运行；或「项目 → 导出」选择 `Windows Desktop` 预设导出 exe（需先安装同版本导出模板）。

> 导出模板下载：Godot 4.4.1 官方 `Godot_v4.4.1-stable_export_templates.tpz`，解压到 `%APPDATA%\Godot\export_templates\4.4.1.stable\`。

## 目录结构

```

  scenes/                地图、玩家、敌人、Boss、NPC、交互物场景
  scripts/autoload/      配置、状态、背包、任务、存档、音频、地图切换、UI 等单例
  scripts/player/        玩家状态机
  scripts/enemies/       敌人 AI、Boss、预警渲染
  scripts/world/         地图构建器、NPC、宝箱、机关、大门、阶梯、拾取物
  scripts/ui/            标题与主场景
  data/                  集中配置：数值、物品、敌人、技能、任务、NPC、对话、地图（ASCII）
  assets/                程序生成的像素素材、音频、Noto Sans SC 字体
  tests/                 headless 测试套件
  export_presets.cfg     Windows 导出预设（内嵌 pck）
tools/                   资源生成与校验脚本（像素美术、音频、地图、连通性检查）
验证截图/                 实际运行截图（1280×720）
说明.txt                  玩家向说明（启动、按键、存档、已知问题）
验证记录.md               完整验证与问题修复记录
```

## 设计要点

- **数据驱动**：数值、物品、敌人、技能、任务、对话、地图均为 JSON / ASCII 文本，便于调参；关键数值集中在 `project/data/balance.json`。
- **地图即文本**：`project/data/maps/*.txt` 用字符网格描述地形与物件，运行时由 `MapBuilder` 构建瓦片与碰撞，便于版本管理与差异审阅。
- **稳定 ID**：物品、敌人、技能、任务、宝箱、机关均有固定 ID；一次性奖励以状态机 + 存档标记防止重复结算。
- **可测试性**：核心逻辑可 headless 运行，测试覆盖数值公式、任务状态机、存档原子性与地图可达性。

## 已知问题

- 受本机开发目录安全策略影响，exe 从受限目录启动可能崩溃；请放在普通文件夹（如桌面）运行。
- 音效为程序合成的极简风格，无语音；像素素材为程序生成，风格统一但精度有限。
- 窗口尺寸非 2 倍/3 倍整数时，像素图会出现轻微非整数缩放。
